## 🔬 Research & Engineering

### 🧠 NeuroMove

**Design and Development of Brain Computer Interface for Assistive Motion Control Rehabilitation and Mobility Applications**

NeuroMove combines EEG-based motor-imagery decoding with hardware acceleration to investigate practical BCI systems for rehabilitation.

**Research pipeline:**

```text
EEG Acquisition
      ↓
Signal Preprocessing
      ↓
Motor Imagery Representation
      ↓
Deep Learning / EEG Decoding
      ↓
Synthetic fNIRS Generation
      ↓
EEG + Synthetic fNIRS Fusion
      ↓
FPGA Acceleration
      ↓
Real-Time Assistive BCI
```

**Key areas:**

- EEG signal processing
- Motor imagery classification
- Attention / CBAM-based architectures
- EEG-to-fNIRS cross-modal generation
- Diffusion-based modeling
- FPGA acceleration
- Zynq-based deployment
- Hardware/software co-design

🔗 **[NeuroMove Repository](https://github.com/Ahmedvini/NeuroMove)**
